# АДМИН-ПАНЕЛЬ - ИСПРАВЛЕНИЕ И ИНСТРУКЦИЯ

## Проблема
Админ-панель была обрезана: видна была только левая панель с вкладками, контент был обрезан черной линией.

## Причина
CSS использовал `position: fixed` для боковой панели с одновременно установленным `margin-left` для контента, что вызывало перекрытие.

## Решение
Изменен CSS в `css/admin.css`:
- Изменен `display: grid` на `display: flex` в `.admin-wrapper`
- Убран `position: fixed` из `.admin-sidebar`
- Добавлен `flex-shrink: 0` для боковой панели
- Изменен `margin-left: 260px` на `flex: 1` в `.admin-content`

## Что изменилось

### ДО (с ошибкой)
```css
.admin-wrapper {
    display: grid;
    grid-template-columns: 260px 1fr;
}

.admin-sidebar {
    position: fixed;  /* ← Ошибка!
    width: 260px;
    height: 100vh;
}

.admin-content {
    margin-left: 260px;  /* ← Перекрытие!
}
```

### ПОСЛЕ (исправлено)
```css
.admin-wrapper {
    display: flex;  /* ← Правильный макет
    min-height: 100vh;
}

.admin-sidebar {
    width: 260px;
    height: 100vh;
    overflow-y: auto;
    flex-shrink: 0;  /* ← Предотвращает сжатие
}

.admin-content {
    flex: 1;  /* ← Занимает оставшееся место
    padding: 2rem;
    overflow-y: auto;
    max-width: 100%;  /* ← Контент видна полностью
}
```

1. Откройте `/admin-login.html`
2. Введите пароль: `admin123`
3. Нажмите "Войти"

**⭐ Отзывы** - Управление отзывами

## Статусы заказов

| Статус | Описание |
|--------|---------|
| `new` | Новый заказ (только что создан) |
| `confirmed` | Заказ подтвержден |
| `packed` | Заказ упакован |
| `shipped` | Заказ отправлен |
| `completed` | Заказ доставлен |

## Часто задаваемые вопросы

**В: Забыл пароль, как восстановить?**
А: Пароль жестко закодирован в коде: `admin123`. Это не может быть изменено без редактирования исходного кода.

**В: Как удалить все данные и начать заново?**
А: Откройте консоль браузера (F12 → Console) и выполните:
```javascript
localStorage.clear();
```
Все данные будут удалены. После этого потребуется повторная регистрация.

**В: Можно ли добавить еще админов?**
А: В текущей версии только один админ. Для добавления нескольких админов нужна кастомная разработка.

**В: Почему контент виден не полностью?**
А: Если это всё еще происходит, откройте консоль браузера (F12 → Console) и проверьте на ошибки.
