# Руководство администратора VAPEBYVAPE.STORE

## Вход в админ-панель

1. Перейдите на страницу входа: `/admin-login.html`
2. Введите пароль администратора: **admin123** (по умолчанию)
3. Нажмите "Войти в админ-панель"

## Структура админ-панели

### 1. Главная (Статистика)
- Общее количество товаров
- Количество зарегистрированных пользователей
- Количество заказов
- Общая выручка

### 2. Товары
Управление каталогом товаров:
- Просмотр всех товаров в таблице
- Добавление новых товаров
- Редактирование информации о товаре
- Удаление товаров

#### Параметры товара:
- **ID** - уникальный идентификатор
- **Название** - название товара
- **Категория** - один из 5 категорий
- **Производитель** - производитель товара
- **Вкус** - описание вкуса
- **Объем** - объем упаковки в мл
- **Цена** - цена в рублях
- **Остаток** - количество в наличии
- **Описание** - полное описание товара

### 3. Заказы
Управление заказами клиентов:
- Просмотр всех заказов
- Изменение статуса заказа
- Просмотр деталей заказа (товары, адрес, клиент)

#### Статусы заказа:
- **new** - Новый (только что получен)
- **confirmed** - Подтвержден (подтвердили клиента)
- **packed** - Собран (товары собраны и упакованы)
- **shipped** - Отправлен (отправлено у курьера/почты)
- **completed** - Завершен (доставлено клиенту)

### 4. Пользователи
Управление учетными записями пользователей:
- Просмотр всех зарегистрированных пользователей
- Информация о пользователе (имя, email, телефон, дата регистрации)
- Удаление пользователя

### 5. Отзывы
Управление отзывами о товарах:
- Просмотр всех поступивших отзывов
- Одобрение/публикация отзывов
- Удаление спама или неправильных отзывов

### 6. Настройки
Конфигурация магазина и интеграций:

#### Основные настройки
- **Название магазина** - как компания известна
- **Телефон** - контактный номер
- **Email** - электронная почта поддержки

#### Настройки Telegram (ВАЖНО!)
Для автоматической отправки заказов в Telegram:

1. **Telegram Bot Token**
   - Перейдите в Telegram, найдите @BotFather
   - Создайте нового бота (/newbot)
   - Скопируйте токен вида: `123456:ABC-DEF1234ghIkl-zyx57W2v1u123ew11`
   - Вставьте его в поле "Telegram Bot Token"

2. **Telegram Chat ID**
   - Это ID чата, где будут приходить заказы
   - Отправьте боту сообщение `/start`
   - Перейдите по ссылке `https://api.telegram.org/bot<YOUR_TOKEN>/getUpdates`
   - Найдите `chat.id` в ответе
   - Вставьте это число в поле "Telegram Chat ID"

3. После сохранения, все новые заказы будут автоматически отправляться в Telegram

## Где хранятся данные?

Все данные хранятся в браузерном хранилище (LocalStorage):

- **vape_users** - список всех пользователей
- **admin_products** - список товаров
- **admin_orders** - список заказов
- **admin_settings** - настройки магазина
- **telegram_token** - токен Telegram бота
- **telegram_chat_id** - ID чата Telegram

## Использование смартфоном

Админ-панель полностью отзывчива и работает на смартфонах, планшетах и ПК.

## Безопасность

- Пароль администратора хранится в локальном коде
- Для увеличения безопасности измените пароль в файле `/admin-login.html`
- В реальном приложении следует использовать защищенное серверное хранилище

## Получение помощи

Если возникли проблемы:
1. Очистите кэш браузера (Ctrl+Shift+Delete)
2. Перезагрузитесь на страницу входа в админ
3. Проверьте, правильно ли введен пароль

## Советы

- Регулярно проверяйте новые заказы в разделе "Заказы"
- Обновляйте остатки товаров после продажи
- Отслеживайте статус заказов для быстрой обработки
- Используйте Telegram для получения уведомлений о заказах в реальном времени
