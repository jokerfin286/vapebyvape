## Интеграция Telegram

### Как настроить (4 шага)

#### Шаг 1: Создайте бота
1. Откройте Telegram
2. Найдите @BotFather
3. Отправьте `/newbot`
4. Следуйте инструкциям
5. **Скопируйте токен**

#### Шаг 2: Получите Chat ID
1. Отправьте сообщение вашему боту
2. Перейдите на: `https://api.telegram.org/bot<ВАШTOKEN>/getUpdates`
3. Найдите `chat.id` в ответе
4. **Скопируйте ID**

#### Шаг 3: Введите в админ-панели
1. Откройте `/admin-login.html`
2. Введите пароль: `admin123`
3. Перейдите в "Настройки"
4. Введите Token и Chat ID
5. Нажмите "Сохранить"

#### Шаг 4: Готово!
- Теперь все новые заказы будут автоматически отправляться в Telegram
- Формат: номер заказа, клиент, адрес, товары, сумма

### Пример сообщения в Telegram

## Хранение данных

Все данные хранятся в браузерном LocalStorage:

```javascript
localStorage.getItem('vape_users')          // Пользователи
localStorage.getItem('admin_products')       // Товары
localStorage.getItem('admin_orders')         // Заказы
localStorage.getItem('vape_cart')           // Корзина текущего пользователя
localStorage.getItem('vape_favorites')      // Избранное
localStorage.getItem('admin_settings')      // Настройки магазина
localStorage.getItem('telegram_token')      // Токен Telegram
localStorage.getItem('telegram_chat_id')    // Chat ID Telegram
```
