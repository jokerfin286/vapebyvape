💬 НАСТРОЙКА TELEGRAM УВЕДОМЛЕНИЙ
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

ШАГ 1: Создайте бота в Telegram
   1. Найдите @BotFather в Telegram
   2. Отправьте /newbot
   3. Следуйте инструкциям
   4. Скопируйте токен (например: 123456:ABC-DEF1234ghIkl...)

ШАГ 2: Получите Chat ID
   1. Отправьте сообщение вашему боту
   2. Откройте: https://api.telegram.org/bot<ТОКЕН>/getUpdates
   3. Найдите "chat": { "id": 123456789... }
   4. Скопируйте это число

ШАГ 3: Введите в админ-панели
   1. Откройте: admin-login.html
   2. Пароль: admin123
   3. Откройте: Настройки
   4. Введите:
      - Telegram Bot Token: [ВАШ ТОКЕН]
      - Telegram Chat ID: [ВАШ ID]
   5. Нажмите: Сохранить настройки

ШАГ 4: Готово!
   ✓ Теперь все заказы будут отправляться в Telegram в реальном времени
