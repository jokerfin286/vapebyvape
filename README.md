# VAPEBYVAPE.STORE - Премиум интернет магазин жидкостей для вейпинга

Полнофункциональное, готовое к production развертыванию веб-приложение на чистом HTML5, CSS3 и Vanilla JavaScript.

## 🚀 Особенности

- **Без фреймворков** - Чистый HTML5, CSS3, JavaScript
- **Production-ready** - Полностью рабочее приложение с реальной функциональностью
- **Mobile-first** - Адаптивный дизайн для всех устройств
- **Premium дизайн** - 80% премиум стиль, 20% неоновых акцентов
- **Полная каталогизация** - 30+ товаров, 5 категорий, расширенные фильтры
- **Система аутентификации** - Регистрация, вход, профили пользователей
- **Админ-панель** - Полная система управления товарами, заказами, пользователями
- **SEO-оптимизированный** - robots.txt, sitemap.xml, структурированные данные
- **Хранение данных** - localStorage для фронтенда, готово для подключения API

## 🔐 Аутентификация

- Валидация email и пароля
- Проверка возраста (минимум 18 лет)

## 🚀 Развертывание

### На Vercel
```bash
# Клонируйте репозиторий
git clone <repository-url>
cd vapebyvape-store

# Примечание: Vercel автоматически развернет статический сайт
```

### Локальная разработка
Просто откройте `index.html` в браузере или используйте любой локальный HTTP-сервер:

```bash
# Python 3
python -m http.server 8000

# Python 2
python -m SimpleHTTPServer 8000

# Node.js (при установленном http-server)
npx http-server
```

## 🔌 API интеграция (готово для подключения)

Все файлы готовы для подключения реального API:

```javascript
// Примеры замены mockProducts на API вызовы
// В app.js измените:
// const mockProducts = [...] на fetch('/api/products')

// API endpoints, которые нужно реализовать:
// GET  /api/products      - Получить все товары
// POST /api/products      - Создать товар (админ)
// GET  /api/orders        - Получить заказы (админ)
// POST /api/orders        - Создать заказ
// POST /api/users         - Регистрация
// POST /api/auth/login    - Вход
// GET  /api/users/:id     - Получить профиль
```
