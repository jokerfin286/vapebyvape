## ШАГ 1: Подготовка GitHub

### 1.1 Создайте аккаунт на GitHub
- Откройте https://github.com
- Sign Up (Зарегистрируйтесь)

### 1.2 Создайте новый репозиторий
1. Нажмите **New Repository** (зеленая кнопка)
2. Repository name: `vapebyvape` (или ваше имя)
3. Description: `VAPEBYVAPE.STORE - E-commerce shop`
4. Выберите **Public** (открытый)
5. **Create repository**

---

## ШАГ 2: Загрузка файлов на GitHub

### Вариант А: Через GitHub Desktop (проще для начинающих)

1. Скачайте GitHub Desktop: https://desktop.github.com
2. Установите программу
3. Sign in с вашим GitHub аккаунтом
4. File → Clone Repository
5. Выберите `YOUR_USERNAME/vapebyvape`
6. Выберите папку для сохранения
7. **Clone**
8. Скопируйте все файлы сайта в папку проекта
9. В GitHub Desktop должны появиться все файлы
10. Commit to main → введите сообщение "Initial commit"
11. **Publish branch**

### Вариант Б: Через командную строку (для продвинутых)

```bash
# 1. Перейдите в папку с проектом
cd /путь/к/vapebyvape

# 2. Инициализируйте репозиторий
git init

# 3. Добавьте все файлы
git add .

# 4. Создайте первый коммит
git commit -m "Initial commit - VAPEBYVAPE.STORE v1.1.3"

# 5. Переименуйте ветку на main
git branch -M main

# 6. Добавьте удаленный репозиторий
git remote add origin https://github.com/YOUR_USERNAME/vapebyvape.git

# 7. Отправьте файлы на GitHub
git push -u origin main
```

### Вариант В: Через веб-интерфейс GitHub (самый простой)

1. На странице репозитория нажмите **Add file → Upload files**
2. Перетащите все файлы (можно мультивыделение)
3. Нажмите **Commit changes**

---

## ШАГ 3: Включение GitHub Pages

### 3.1 Откройте настройки репозитория
1. На странице репозитория нажмите **Settings**
2. В левом меню выберите **Pages**

### 3.2 Настройте GitHub Pages
1. Source: выберите **Deploy from a branch**
2. Branch: выберите **main**
3. Folder: выберите **/ (root)**
4. Нажмите **Save**

### 3.3 Дождитесь развертывания
1. Вверху появится сообщение "Your site is live at..."
2. Это займет 1-2 минуты
3. Ваш сайт доступен по адресу:
   ```
   https://YOUR_USERNAME.github.io/vapebyvape
   ```

## ШАГ 4: Настройка Telegram бота

### 4.1 Создайте Telegram бота

1. Откройте Telegram
2. Найдите **@BotFather**
3. Отправьте команду: `/newbot`
4. BotFather спросит имя:
   ```
   Название: VAPEBYVAPE Bot
   ```
5. BotFather спросит username:
   ```
   Username: vapebyvape_shop_bot
   ```
6. **Скопируйте токен!** (он выглядит так: `123456789:ABCDefGhIjKlMnOpQrStUvWxYz1234567890`)

### 4.2 Получите Chat ID

**Способ 1: Личный чат (вам самому)**

1. Найдите в Telegram **@userinfobot**
2. Отправьте `/start`
3. Скопируйте ваш **User ID** (это ваш Chat ID с минусом, например: `-123456789`)

**Способ 2: Группа (рекомендуется для масштабирования)**

1. Создайте новую группу в Telegram
2. Добавьте вашего бота (@vapebyvape_shop_bot)
3. Напишите сообщение в группе
4. Найдите **@userinfobot** и добавьте в группу
5. Отправьте `/info`
6. Скопируйте **Group ID** (это ваш Chat ID, например: `-123456789`)

### 4.3 Введите настройки на сайте

1. Откройте ваш сайт: `https://YOUR_USERNAME.github.io/vapebyvape`
2. Нажмите на админ-панель (внизу или в меню)
3. Откройте `/admin-login.html`
4. Пароль: `admin123`
5. Перейдите в **Настройки**
6. Вставьте:
   - **Telegram Bot Token:** `123456789:ABCDefGhIjKlMnOpQrStUvWxYz1234567890`
   - **Telegram Chat ID:** `-123456789`
7. Нажмите **Сохранить настройки**
8. Должно появиться сообщение "Настройки сохранены"

## ШАГ 6: Дополнительно (опционально)

### 6.1 Подключить собственный домен

1. Купите доменное имя (например, на GoDaddy, Namecheap)
2. В настройках домена добавьте CNAME запись:
   ```
   Name: www
   Value: YOUR_USERNAME.github.io
   ```
3. В GitHub Pages Settings → Custom domain: `www.yourdomain.com`

### 6.2 Включить HTTPS

1. GitHub Pages автоматически включает HTTPS
2. В Settings → Pages включите "Enforce HTTPS"

## Проблемы и решения

### Сайт не загружается

```
Решение:
1. Дождитесь завершения развертывания (может занять 5 минут)
2. Очистите кэш браузера (Ctrl+Shift+Delete)
3. Перезагрузите страницу (Ctrl+F5)
```

### Админ-панель не открывается

```
Решение:
1. Убедитесь, что файл admin-login.html существует
2. Проверьте путь в браузере: /admin-login.html
3. Очистите кэш и перезагрузите
```

### Telegram не отправляет сообщения

```
Решение:
1. Проверьте что токен и Chat ID правильные
2. Убедитесь что бот добавлен в группу/чат
3. Проверьте консоль браузера (F12 → Console) на ошибки
4. Создайте нового бота через @BotFather
```
